Docker commands

in cmd we need to run these commands

docker  ---> This will give wheather the docker is installed or not

docker --version =====> To see the version

docker pull busybox =====> here busy box is an image and we are pulling into our system

docker run busybox ls ====> used to run the busybox, which is pulled in the previous step

docker container ps -a    ====> to see the container which is running

docker container rm <<containerId>> ====> used to delete the container
